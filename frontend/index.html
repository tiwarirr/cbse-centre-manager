Invigilator Demand

School-wise report · Requirement input · Letter generation
ℹ️
This report shows date-wise, class & subject-wise candidate count per school. Use it to decide how many invigilators to demand from each school. Private candidates are shown for total strength accuracy but are excluded from Step 2 requirements.
✏️
Enter the number of invigilators to demand from each school. The CS decides based on the school report above. Click Save Requirements when done.
📨
Letters are generated for all schools with invigilator requirements set. Use Generate Letters to open the printable view. You can edit the template below before generating.
